# 프로모션 코드 복사 버튼 디자인

## 목표

메인(`/`)과 토너(`/toner`) 페이지의 이미지에 포함된 프로모션 코드 `HNRF8MQN`을 사용자가 바로 복사할 수 있게 한다. 기존 아트워크의 정렬과 비율은 바꾸지 않고, 이미지 속 코드 배너를 같은 디자인의 HTML 버튼으로 정확히 덮어 배너 전체를 복사 인터페이스로 만든다.

## 결정된 범위

- 두 페이지 모두 같은 재사용 가능한 프로모션 코드 복사 버튼을 사용한다.
- 버튼은 각 이미지 컨테이너 안에서 기존 코드 배너를 덮도록 절대 위치로 오버레이한다.
- 코드 배너의 가로 위치는 두 이미지에서 거의 같으므로 같은 가로 기준을 사용하고, 이미지 높이가 다른 점을 반영해 세로 위치는 페이지별로 조정한다.
- 기존 아트워크의 밝은 파랑에서 진한 파랑으로 이어지는 그라데이션, 흰색 문구, 캡슐 형태를 재현한다.
- 버튼에는 `Promo Code: [HNRF8MQN]`을 표시하고 오른쪽 끝에 반투명한 원형 복사 아이콘을 내장한다.
- 캡슐 전체를 클릭 또는 터치할 수 있어 별도의 작은 터치 영역에 의존하지 않는다.
- 성공하면 복사 아이콘이 약 1.5초 동안 체크 아이콘으로 바뀐다.
- 키보드 포커스와 스크린 리더용 버튼 이름 및 상태 안내를 제공한다.

## 제외 범위

- 원본 이미지 파일의 편집 또는 프로모션 문구 재제작
- 별도의 상시 노출 텍스트 버튼이나 성공 토스트
- Amazon CTA, 할인율 문구, 링크 및 추적 이벤트 변경
- 다른 상품 페이지로의 확대 적용

## 아키텍처와 주요 컴포넌트

복사 동작, 배너 UI, 아이콘 상태를 담당하는 공용 컴포넌트를 만든다. 컴포넌트는 복사할 코드와 페이지별 위치 스타일을 입력받고, 각 페이지는 이미지와 버튼을 같은 `relative` 컨테이너 안에 배치한다.

위치는 렌더링된 이미지 컨테이너를 기준으로 한 비율 좌표로 지정한다. 따라서 모바일과 데스크톱에서 이미지가 동일 비율로 축소되면 버튼도 코드 배너를 따라 이동한다. 최종 좌표는 실제 브라우저 렌더링을 보면서 `/`와 `/toner`에서 각각 미세 조정한다.

외부 아이콘 라이브러리는 추가하지 않고 현재 프로젝트 방식에 맞는 간단한 인라인 SVG를 사용한다.

## 데이터 모델·계약 변경

서버 데이터나 외부 API 계약 변경은 없다. 클라이언트에서 복사할 프로모션 코드 문자열만 공용 컴포넌트에 전달한다.

## 오류 처리 정책

우선 브라우저 Clipboard API를 사용하고, 지원되지 않거나 실패할 경우 호환용 복사 방식을 한 번 시도한다. 실제 복사가 성공한 경우에만 체크 상태를 표시한다. 두 방식이 모두 실패하면 성공 표시를 하지 않고 접근성 상태 메시지로 실패를 알린다.

컴포넌트가 해제될 때 상태 복원 타이머를 정리해 불필요한 상태 변경을 방지한다.

## 테스트 전략

- `pnpm lint`, `pnpm typecheck`, `pnpm build`를 실행한다.
- 메인 페이지와 `/toner`에서 버튼 클릭 시 정확히 `HNRF8MQN`이 복사되는지 확인한다.
- 성공 시 복사 아이콘이 체크 아이콘으로 바뀌고 약 1.5초 후 복원되는지 확인한다.
- 375px, 430px, 750px 너비와 일반 데스크톱 화면에서 버튼이 기존 코드 배너를 완전히 덮고 이미지나 CTA를 가리지 않는지 브라우저로 확인한다.
- 키보드 포커스 표시, 버튼 이름, 상태 알림을 확인한다.

## 완료 기준

- `/`와 `/toner` 모두에서 프로모션 코드를 한 번의 버튼 클릭으로 복사할 수 있다.
- 버튼이 두 이미지의 기존 코드 배너를 자연스럽게 대체하며 원래 아트워크의 디자인과 어울린다.
- 화면 크기가 바뀌어도 버튼이 이미지와 함께 이동하며 레이아웃을 밀거나 가로 스크롤을 만들지 않는다.
- 복사 성공 여부가 아이콘 변화로 명확히 전달되고 키보드 및 스크린 리더로도 사용할 수 있다.
- 기존 Amazon CTA 및 페이지 동작이 유지되고 필수 검증 명령이 통과한다.
